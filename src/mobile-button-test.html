Root Cause Analysis

Bug 1 — Home.jsx line 204
The mobile SwipeableDrawer content wraps DealDetailPanel in:
<Box sx={{ height: "100%", overflowY: "auto" }}>
This makes the outer wrapper scroll the entire panel as one block. Because the drawer has overflow:hidden, the DealDetailPanel's inner flex:1 scroll area can grow unbounded — pushing the Directions and Share buttons outside the visible drawer viewport. The buttons exist in the DOM but cannot be scrolled to.
Bug 2 — DealDetailPanel.jsx line 356
The inner scrollable Box uses flex:1; overflowY:"auto" but is missing minHeight:0. In CSS Flexbox, the default min-height of a flex child is auto (its content size), so the child cannot shrink below its full content height — the scroll containment breaks.
Fix 1 — Home.jsx line 204
Change the wrapper Box:
sx={{ height: "100%", overflowY: "auto" }}
To:
sx={{ flex: 1, overflow: "hidden", minHeight: 0 }}
Fix 2 — DealDetailPanel.jsx line 356
Add minHeight: 0 to the inner scrollable Box:
sx={{ flex: 1, overflowY: "auto", "&::-webkit-scrollbar": { width: 0 }, scrollbarWidth: "none" }}
To:
sx={{ flex: 1, overflowY: "auto", minHeight: 0, "&::-webkit-scrollbar": { width: 0 }, scrollbarWidth: "none" }}
